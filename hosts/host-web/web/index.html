Skyrim Runtime

Boots your own dumped title, renders it with WebGPU and logs every kernel import it calls. Game files and saves stay in this browser's private storage.

Controller: the first connected gamepad, or keyboard and mouse — WASD move, mouse (click the game to capture it, Esc to release) or arrows look, left/right click or C/Z right/left triggers, Space A, Tab or Esc B, R X, F Y, Q/E bumpers, Enter Start, Backspace Back, 1–4 D-pad.
